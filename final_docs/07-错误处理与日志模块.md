# 错误处理与日志模块

## 模块职责

提供统一的错误码定义、退出码转换，以及控制台日志输出功能。

| 文件 | 行数 | 职责 |

| [log.h](../include/log.h) | 17 | 控制台日志/错误输出工具函数 |

## ErrorCode 枚举

文件：[error_codes.h](../include/error_codes.h)

```cpp
// [error_codes.h:4-15]
enum class ErrorCode {
    Ok = 0,                // 编译成功
    Usage = 2,             // 命令行参数错误
    InvalidExtension = 3,  // 非 .pas 扩展名
    InputNotFound = 4,     // 输入文件不存在
    InputUnreadable = 5,   // (预留) 输入不可读
    OutputCreateFailed = 6,// 无法创建输出文件
    LexicalError = 7,      // 词法错误
    SyntaxError = 8,       // 语法错误
    SemanticError = 9,     // 语义错误
    GenerationError = 10,  // 代码生成错误
};

// [error_codes.h:17-19]
inline int toExitCode(ErrorCode code) {
    return static_cast<int>(code);  // 直接取枚举值作为进程退出码
}
```

## 日志模块

文件：[log.h](../include/log.h)

```cpp
// [log.h:8-15]
namespace logutil {

inline void info(const std::string& msg) {
    std::cout << "[INFO] " << msg << std::endl;     // 标准输出
}

inline void error(const std::string& code, const std::string& msg) {
    std::cerr << "[" << code << "] " << msg << std::endl;  // 标准错误
}

}  // namespace logutil
```

极简设计：全部 inline 函数，无额外依赖。info 输出到 stdout，error 输出到 stderr。

## 错误上报模式

各阶段错误上报遵循统一模式：

```
1. 模块内部操作时累积错误到 result.errors 向量
2. 编译驱动检查 errors.empty() 判断是否通过
3. 若失败: 遍历 errors 逐条调用 logutil::error() 输出
4. 最后输出汇总信息 + 返回对应退出码
```

示例（词法阶段）：
```cpp
// [compiler_driver.cpp:33-39]
if (!lexResult.errors.empty()) {
    for (const auto& err : lexResult.errors) {
        logutil::error(err.code, "(" + line:col + ") " + err.message);
    }
    logutil::error("E199", "Lexical analysis failed with N error(s).");
    return toExitCode(ErrorCode::LexicalError);
}
```
