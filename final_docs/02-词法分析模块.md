# 词法分析模块 (Lexer)

## 模块职责

将 Pascal-S 源代码字符串转换为 Token 流，同时检测词法错误（非法字符、未闭合注释、非法字符字面量等）。

## 文件结构

| 文件 | 行数 | 职责 |
|------|------|------|
| [token.h](../include/token.h) | 86 | Token 类型枚举与数据结构定义 |
| [lexer.h](../include/lexer.h) | 27 | Lexer 类接口与 LexerResult 定义 |
| [lexer.cpp](../src/lexer.cpp) | 115 | Flex 扫描器调用封装、Token 类型映射 |
| [lexer_flex.l](../src/lexer_flex.l) | 192 | Flex 词法规则定义（正则 → Token） |

## Token 类型体系

定义于 [token.h](../include/token.h)，共 50+ 种 Token 类型，分为以下几类：

### 分类一览

```
TokenType 枚举
├── 特殊
│   ├── EndOfFile       — 流结束标记
│   └── Unknown         — 无法识别的字符
├── 字面量
│   ├── Identifier      — 标识符 / 关键字
│   ├── IntegerLiteral  — 整数（仅无符号，符号由语法层处理）
│   ├── RealLiteral     — 实数（含小数点）
│   ├── CharLiteral     — 字符字面量 'x'
│   └── BooleanLiteral  — true / false
├── 关键字 (KwXxx)
│   ├── 程序结构: Program, Const, Type, Var, Begin, End
│   ├── 子程序:   Procedure, Function
│   ├── 控制流:   If, Then, Else, Case, While, Repeat, Until, For, To, DownTo, Do
│   ├── I/O:      Read, ReadLn, Write, WriteLn
│   ├── 类型:     Record, Array, Of, Integer, Real, Boolean, Char
│   └── 运算符:   Div, Mod, And, Or, Not
├── 运算符
│   └── Plus, Minus, Multiply, Divide, Assign(:=), Equal, NotEqual(<>),
│       Less, LessEqual, Greater, GreaterEqual
└── 界符
    └── LParen, RParen, LBracket, RBracket, Comma, Semicolon, Colon, Dot, DotDot
```

### 规则分类

#### 空白与注释

```flex
// [lexer_flex.l:136-145]
[ \t\r]+              → 累加列号，不产生 Token
\n                    → 行号+1，列号复位
"//"[^\n]*            → 单行注释，跳过
"{"                   → 进入 COMMENT 状态，记录起始位置
<COMMENT>"{"          → 嵌套注释错误 (E106)
<COMMENT>"}"          → 退出 COMMENT 状态
<COMMENT>\n           → 行号+1
<COMMENT><<EOF>>      → 未闭合注释错误 (E107)
```

#### 运算符与界符（按长度优先匹配）

```flex
// [lexer_flex.l:147-167]
":="   → T_ASSIGN        // 双字符优先匹配
"<="   → T_LESS_EQUAL
">="   → T_GREATER_EQUAL
"<>"   → T_NOT_EQUAL
".."   → T_DOTDOT
// 单字符在此之后
"+"    → T_PLUS
"-"    → T_MINUS
...
```

#### 字面量

```flex
// [lexer_flex.l:169-180]
[0-9]+"."[0-9]+    → T_REAL       // 实数：必须含小数点
[0-9]+             → T_INTEGER    // 整数
'([^\\\'\n\r])'    → T_CHAR       // 合法字符字面量（单个非特殊字符）
'([^\'\n\r]|\\.)*' → E109 错误     // 过长字符字面量
```

#### 标识符与关键字

```flex
// [lexer_flex.l:182-186]
[A-Za-z_][A-Za-z0-9_]*  → 先小写化，再查关键字表
                         匹配则返回对应关键字 Token
                         否则返回 T_IDENTIFIER
```

关键字表定义于 `keywordOrIdentifier()` 函数（[lexer_flex.l:47-92]），共映射 30+ 个 Pascal 关键字。

#### 错误恢复

```flex
// [lexer_flex.l:188-191]
.  → E110 错误 "Unknown character"，返回 T_UNKNOWN
```

## 错误处理

| 错误码 | 触发条件 | 位置 |
|--------|---------|------|
| E106 | 嵌套注释 `{ ... {` | [lexer_flex.l:141] |
| E107 | 未终止注释 `{ ... EOF` | [lexer_flex.l:145] |
| E109 | 非法字符字面量（多字符/转义） | [lexer_flex.l:173-180] |
| E110 | 无法识别的字符 | [lexer_flex.l:188-191] |

所有错误存入 `LexError` 结构体：
```cpp
// [lexer.h:9-13]
struct LexError {
    std::string code;
    std::string message;
    SourcePosition pos;
};
```

## 数据流输出

```
Lexer::tokenizeDetailed(source)
  → LexerResult {
      tokens: [Token, Token, ..., EndOfFile]   // Token 序列 + EOF 哨兵
      errors: [LexError, ...]                   // 词法错误列表
    }
```
