# 编译驱动与主程序 (Compiler Driver & Main)

## 模块职责

编译驱动是整个编译流水线的**编排者**，负责：
- 解析命令行参数
- 按顺序调用词法→语法→语义→代码生成四个阶段
- 在每个阶段之间做错误检查（任一阶段失败即停止）
- 管理文件输入输出

    // 1. 参数校验: 必须是 -i <input.pas> 格式                          [line 14-17]

## 错误处理策略

编译器采用 **fail-fast** 策略：任一阶段检测到错误即停止后续阶段。错误信息格式为：

```
[ERROR_CODE] (line:column) message
```

示例输出：
```
[E001] Input file must have .pas extension: test.txt
[E110] (1:5) Unknown character: @
[E201] (3:10) Syntax error: syntax error
[S103] (5:3) Undefined identifier in use: x
```

成功时输出：
```
[INFO] Input:  samples/01_features.pas
[INFO] Output: samples/01_features.c
[INFO] Tokenized items: 23
[INFO] Syntax stage: passed
[INFO] Semantic stage: passed
[INFO] Codegen stage: template emitted
```

## 退出码体系

定义于 [error_codes.h](../include/error_codes.h)：

| 退出码 | ErrorCode 枚举值 | 含义 |
|--------|-----------------|------|
| 0 | Ok | 编译成功 |
| 2 | Usage | 命令行参数错误 |
| 3 | InvalidExtension | 输入文件非 .pas 扩展名 |
| 4 | InputNotFound | 输入文件不存在或不可读 |
| 5 | InputUnreadable | (预留) 输入文件不可读 |
| 6 | OutputCreateFailed | 无法创建输出 .c 文件 |
| 7 | LexicalError | 词法分析阶段失败 |
| 8 | SyntaxError | 语法分析阶段失败 |
| 9 | SemanticError | 语义分析阶段失败 |
| 10 | GenerationError | 代码生成阶段失败 |
