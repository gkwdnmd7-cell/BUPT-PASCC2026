# 语法分析模块 (Parser)

## 模块职责

将词法分析器输出的 Token 流按 Pascal-S 文法进行语法结构验证。如果语法正确，返回一个（当前为空壳的）AST 根节点；如果存在语法错误，收集所有错误信息。

## 文法设计

文件：[parser_bison.y](../src/parser_bison.y)

### Token 声明

```yacc
// [parser_bison.y:8-16]
%token T_UNKNOWN T_IDENTIFIER T_INTEGER T_REAL T_CHAR T_BOOLEAN
%token T_PROGRAM T_CONST T_TYPE T_VAR T_PROCEDURE T_FUNCTION ...
%token T_PLUS T_MINUS T_MULTIPLY T_DIVIDE T_DIV T_MOD T_AND T_OR T_NOT
%token T_ASSIGN T_EQUAL T_NOT_EQUAL T_LESS T_LESS_EQUAL ...

// [parser_bison.y:18-21]  优先级与结合性声明
%left T_OR
%left T_PLUS T_MINUS
%left T_MULTIPLY T_DIVIDE T_DIV T_MOD T_AND
%right T_NOT
```

优先级从低到高：OR < +/- < */div/mod/and < NOT

### 产生式总览（按 Pascal-S 标准文法组织）

#### 1. 程序结构

```
program           → program_head program_body T_DOT
program_head      → T_PROGRAM T_IDENTIFIER T_LPAREN id_list T_RPAREN T_SEMICOLON
                  | T_PROGRAM T_IDENTIFIER T_LPAREN T_RPAREN T_SEMICOLON
                  | T_PROGRAM T_IDENTIFIER T_SEMICOLON
program_body      → const_declarations type_declarations var_declarations
                    subprogram_declarations compound_statement
```
*位置：[parser_bison.y:25-37]*

#### 2. 常量声明

```
const_declarations → ε | T_CONST const_declaration T_SEMICOLON
const_declaration  → T_IDENTIFIER T_EQUAL const_value
                   | const_declaration T_SEMICOLON T_IDENTIFIER T_EQUAL const_value
const_value        → [+-]? num | T_CHAR | T_BOOLEAN | [+-]? T_IDENTIFIER
```
*位置：[parser_bison.y:44-64]*

> 注：`const_declarations` 只声明了一个 `const_declaration`，多常量通过 `const_declaration` 内部的左递归实现。

#### 3. 类型声明

```
type_declarations → ε | T_TYPE type_declaration T_SEMICOLON
type_declaration  → T_IDENTIFIER T_EQUAL type_spec
                  | type_declaration T_SEMICOLON T_IDENTIFIER T_EQUAL type_spec
type_spec         → basic_type
                  | T_ARRAY T_LBRACKET periods T_RBRACKET T_OF type_spec  ← 多维数组
                  | T_RECORD record_body T_END                            ← 记录类型
                  | T_IDENTIFIER                                           ← 类型别名
basic_type        → integer | real | boolean | char
```
*位置：[parser_bison.y:71-100]*

#### 4. 变量声明

```
var_declarations  → ε | T_VAR var_declaration T_SEMICOLON
var_declaration   → id_list T_COLON type_spec
                  | var_declaration T_SEMICOLON id_list T_COLON type_spec
```
*位置：[parser_bison.y:110-119]*

#### 5. 子程序（过程/函数）

```
subprogram_declarations → ε
                        | subprogram_declarations subprogram_declaration T_SEMICOLON
subprogram_declaration  → subprogram_head subprogram_body
subprogram_head → T_FUNCTION T_IDENTIFIER formal_parameter T_COLON basic_type T_SEMICOLON
                | T_PROCEDURE T_IDENTIFIER formal_parameter T_SEMICOLON
formal_parameter → ε | T_LPAREN parameter_lists T_RPAREN | T_LPAREN T_RPAREN
parameter_lists  → parameter_list | parameter_lists T_SEMICOLON parameter_list
parameter_list   → var_parameter | value_parameter
var_parameter    → T_VAR value_parameter       ← VAR 引用参数
value_parameter  → id_list T_COLON basic_type
subprogram_body  → const_declarations type_declarations var_declarations compound_statement
```
*位置：[parser_bison.y:121-161]*

#### 6. 语句

```
compound_statement → T_BEGIN statement_list_opt T_END                       [y:163-165]
statement_list     → stmt | statement_list T_SEMICOLON stmt                 [y:172-176]

stmt → identifier_stmt    — 赋值 / 过程调用
     | compound_statement — begin...end 块
     | if_stmt            — if...then...else
     | case_stmt          — case...of...end
     | while_stmt         — while...do
     | repeat_stmt        — repeat...until
     | for_stmt           — for...to/downto...do
     | read_stmt          — read/readln
     | write_stmt         — write/writeln
     | ε                  — 空语句
```
*位置：[parser_bison.y:178-190]*

#### 7. 表达式（带优先级）

```
expression       → simple_expression | simple_expression relop simple_expression
relop            → = | <> | < | <= | > | >=
simple_expression → term | simple_expression addop term
addop            → + | - | or
term             → factor | term mulop factor
mulop            → * | / | div | mod | and
factor           → num | variable | ID(expr_list_opt) | (expression)
                 | NOT factor | -factor | +factor | char | boolean
```
*位置：[parser_bison.y:292-340]*

表达式优先级由产生式嵌套层次 + Bison `%left`/`%right` 声明共同保证。

### 错误恢复

4 处错误恢复产生式，用于跳过错误并继续解析：

```
// [parser_bison.y:52]   常量声明内部错误恢复
const_declaration → ... T_SEMICOLON error { yyerrok; }

// [parser_bison.y:118]  变量声明内部错误恢复
var_declaration → ... T_SEMICOLON error { yyerrok; }

// [parser_bison.y:175]  语句列表错误恢复
statement_list → ... error T_SEMICOLON { yyerrok; }

// [parser_bison.y:188]  单语句错误恢复
stmt → error { yyerrok; }
```

## AST 节点体系（占位）

文件：[ast.h](../include/ast.h)

```cpp
// [ast.h:7-46]
enum class AstKind { Program, Statement, Expression };

class AstNode {
    AstKind kind_;
    std::vector<std::shared_ptr<AstNode>> children_;
public:
    void addChild(std::shared_ptr<AstNode> child);
};

class ProgramNode    : public AstNode { ... };  // 程序根节点
class StatementNode  : public AstNode { ... };  // 语句节点
class ExpressionNode : public AstNode { ... };  // 表达式节点
```

当前仅定义节点类型枚举和子节点列表，**未填充任何具体信息**（如运算符类型、标识符名称、字面量值等）。Bison 的语义动作也未向 AST 写入数据。

## 数据流

```
Parser::parse(tokens)
  → parseWithBison(tokens)
    → yyparse() 使用 Bison 文法验证语法
    → ParserResult {
        errors: [ParseError, ...]          // E201 语法错误
        root: shared_ptr<ProgramNode>      // 成功时为占位空节点
      }
```
