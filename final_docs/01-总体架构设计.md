# 总体架构设计

## 项目概述

**pascc**（Pascal-S to C Compiler）是一个将 Pascal-S（教学用简化 Pascal）源程序翻译为 C 语言代码的编译器，作为《编译原理与技术课程设计》的课程项目。采用经典的 4 阶段编译流水线架构。

## 编译流水线

```
┌──────────────┐    ┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│  词法分析     │    │  语法分析     │    │  语义分析     │    │  代码生成     │
│  (Lexer)     │───→│  (Parser)    │───→│  (Semantic)  │───→│  (Codegen)   │
│              │    │              │    │              │    │              │
│ .pas → Token │    │ Token → AST  │    │ AST → 校验   │    │ Token → .c   │
└──────────────┘    └──────────────┘    └──────────────┘    └──────────────┘
```

- **输入**：`.pas` 后缀的 Pascal-S 源文件
- **输出**：同名 `.c` 后缀的 C 语言源文件
- **命令行**：`pascc -i <input.pas>`

## 重要架构决策

### 1. 两套解析器并存
- **Bison 解析器**（`parser_bison.y` + `parser_bison_bridge.cpp`）：负责语法正确性验证，直接输出空 AST 根节点
- **手写递归下降代码生成器**（`code_generator.cpp`）：重新遍历 token 流，直接生成 C 代码，完全不使用 AST

### 2. AST 仅作占位
`ast.h` 中定义了 `ProgramNode`/`StatementNode`/`ExpressionNode` 三种 AST 节点类型，但目前仅含骨架（kind 枚举 + children 列表），Bison 语义动作也未填充具体 AST 节点

### 3. 语义分析独立工作
语义分析器（`semantic_declaration.cpp`）自己重新遍历 token 流，使用独立的 `ScopeStack` + `TableSet` 链表式符号表体系，不依赖 AST 也不依赖代码生成器

### 4. 代码生成采用"直译"策略
`code_generator.cpp`（约 1480 行）对 token 流做递归下降模式匹配，逐结构翻译为等效 C 语法

## 技术栈

| 技术 | 用途 |
|------|------|
| C++17 | 核心语言 |
| CMake 3.16+ | 构建系统 |
| Flex (win_flex) | 词法分析器生成 |
| Bison (win_bison) | 语法分析器生成（LALR(1)） |
| CTest | 测试框架 |
| 静态链接 (`-static`) | Linux 下生成可移植二进制 |
