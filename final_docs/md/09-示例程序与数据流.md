# 示例程序与端到端数据流

## 示例程序概览

`samples` 目录包含 6 组 Pascal-S 源文件及其编译输出的 C 文件，按照功能复杂度从低到高排列，覆盖了从空程序到实数运算的全部已支持特性：

| 文件 | Pascal 源码 | C 输出 | 覆盖特性 |
|------|-----------|--------|---------|
| 00_main | `00_main.pas` | `00_main.c` | 空程序（仅 `begin end.`）——验证最小编译流水线通路 |
| 01_features | `01_features.pas` | `01_features.c` | 变量声明、赋值语句、write 输出——基本翻译能力 |
| 02_lex_error | `02_lex_error.pas` | — (预期失败) | 词法错误用例（非法字符 `@`、未闭合注释等） |
| 03_controlflow | `03_controlflow.pas` | `03_controlflow.c` | 全部 7 种控制流语句：while/if-else/for-to/for-downto/repeat/case |
| 04_routines | `04_routines.pas` | `04_routines.c` | procedure/function 声明、调用、返回值、全局变量闭包访问 |
| 05_realmap | `05_realmap.pas` | `05_realmap.c` | float 类型映射、实数函数参数/返回、实数字面量、实数 I/O |

## 逐示例详细分析

### 00_main — 最小空程序

**Pascal 源码**（`00_main.pas`）：
```pascal
program sample;
begin
end.
```

**翻译要点**：空程序体——`program_body` 中的五部分（const/type/var/subprogram/compound）全部为空产生式。生成的 C 代码包含空的 `main()` 函数和所有运行时 I/O helper（即使未被使用也会生成，确保模板完整）。

### 01_features — 基本特性

**翻译关键映射**：
- `var a1, b2: integer` → `int a1 = 0; int b2 = 0;`（全局变量初始化为 0）
- `a1 := 12` → `a1 = 12;`（Pascal 赋值 `:=` → C 赋值 `=`）
- `write(a1)` → `pas_write_int(a1);`（通过 `inferWriteType()` 判断 a1 的类型为 int，调用对应的 helper）

### 02_lex_error — 词法错误

包含非法字符（如 `@`、未闭合的字符串字面量等），预期行为：词法分析阶段报错 `E110 Unknown character`，`CompilerDriver` 在 fail-fast 策略下输出所有词法错误后退出（退出码 7），不生成 `.c` 文件。

### 03_controlflow — 控制流语句

该示例覆盖了全部 7 种控制流结构的翻译。各结构的关键转换：

| Pascal 结构 | C 翻译 | 特殊处理 |
|------------|--------|---------|
| `while i < 3 do ...` | `while (i < 3) { ... }` | 条件包围括号 |
| `if i = 1 then ... else ...` | `if (i == 1) { ... } else { ... }` | `=` → `==` |
| `for i := 1 to 2 do ...` | `for (i = 1; i <= 2; ++i) { ... }` | `:=` → `=`, `to` → `<=`, 自动 `++i` |
| `for i := 3 downto 1 do ...` | `for (i = 3; i >= 1; --i) { ... }` | `downto` → `>=`, 自动 `--i` |
| `repeat ... until cond` | `do { ... } while (!(cond));` | `until` → `while (!(...))` 条件取反 |
| `case x of 1,2: s1; 3: s2 end` | `switch (x) { case 1: case 2: s1; break; case 3: s2; break; }` | 逗号多值 → case 穿透 |

### 04_routines — 过程与函数

**Pascal 源码**（`04_routines.pas`）：
```pascal
program routines;
var x: integer;

procedure inc1(a: integer);
begin
  x := x + a
end;

function add1(v: integer): integer;
begin
  add1 := v + 1
end;

begin
  x := 1;
  inc1(2);
  x := add1(x)
end.
```

**翻译关键要点**：
- `procedure inc1(a: integer)` → `void inc1(int a)`
- `function add1(v: integer): integer` → `int add1(int v)`
- 函数名赋值 `add1 := v + 1` → `__ret_add1 = v + 1; return __ret_add1;`（通过 `StatementContext.currentFunctionRetVar` 识别并转换）
- 全局变量 `x` 在过程体 `inc1` 中被修改——代码生成器通过两遍扫描策略（第一遍收集函数签名，第二遍翻译）正确处理了函数在定义前被调用的情况
- Pascal 中函数可以递归调用自身（函数名已在父作用域中注册后才进入函数体），生成的 C 代码自然支持递归

### 05_realmap — 实数类型

**翻译关键要点**：
- Pascal `real` → C `float`：类型映射通过 `mapTypeTokenToC()` 实现
- `function addh(v: real): real` → `float addh(float v)`
- `x := 1.25` → `x = 1.25;`（实数字面量直接透传）
- `write(x)` → `pas_write_real(x);`（`inferWriteType()` 检测到变量类型为 float）
- 实数常量：`const pi = 3.14` → `static const float pi = 3.14f;`

## Pascal-S 语言覆盖范围

### 已支持的特性

| 特性 | 状态 | 示例 |
|------|------|------|
| 程序结构 | program...begin...end. | program demo; begin end. |
| 基本类型 | integer, real, boolean, char | var x: integer |
| 数组 | 多维、自定义上下界 | array[1..10, 1..5] of real |
| 常量 | 整数、实数、字符、布尔 | const pi = 3.14 |
| 赋值 | := | a := a + 1 |
| 算术运算 | +, -, *, /, div, mod | a + b * c |
| 逻辑运算 | and, or, not | (a > 0) and (b < 10) |
| 关系运算 | =, <>, <, <=, >, >= | if a <> b then |
| 条件 | if-then-else | if x > 0 then ... else ... |
| 多分支 | case-of | case x of 1,2: ...; 3: ... end |
| 循环 | while-do, for-to/downto-do, repeat-until | for i := 1 to 10 do |
| 过程 | 带参数（含 VAR 引用参数） | procedure p(var x: integer) |
| 函数 | 带返回值 | function f(x: integer): integer |
| I/O | read/readln, write/writeln | write('Hello') |
| 注释 | { ... }, // ... | { block comment } |
