# 语义分析模块 (Semantic Declaration Analyzer)

## 模块职责

在语法分析通过后，对程序进行语义正确性检查，包括：
- 标识符的声明前使用检测
- 同一作用域内重复定义检测
- 类型兼容性检查（表达式、赋值、参数传递）
- 过程/函数调用的参数数量与类型匹配


### 语句语义检查

```cpp
    switch (current().type) {
        Identifier → parseIdentifierStatementSemantics()   // 赋值/调用
        KwBegin    → analyzeCompoundStatement()
        KwIf       → parseIfStatementSemantics()           // 条件必须 boolean
        KwWhile    → parseWhileStatementSemantics()        // 条件必须 boolean
        KwRepeat   → parseRepeatStatementSemantics()       // 条件必须 boolean

        KwRead/Xx  → parseReadStatementSemantics()         // 参数必须变量

    }
}
```
