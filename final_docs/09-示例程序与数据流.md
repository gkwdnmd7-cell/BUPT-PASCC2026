| 文件 | Pascal 源码 | C 输出 | 覆盖特性 |
|------|-----------|--------|---------|
| 00_main | [00_main.pas](../samples/00_main.pas) | [00_main.c](../samples/00_main.c) | 空程序（仅 begin end.） |
| 01_features | [01_features.pas](../samples/01_features.pas) | [01_features.c](../samples/01_features.c) | 变量声明、赋值、write 输出 |

## 逐示例分析

### 00_main — 最小空程序

**Pascal 源码**（[00_main.pas](../samples/00_main.pas)）：
```pascal
program sample;
begin
end.
```

**翻译要点**：空程序体，生成空的 `main()` 函数。

### 01_features — 基本特性

**Pascal 源码**（[01_features.pas](../samples/01_features.pas)）：
```pascal
program demo;
var a1, b2: integer;
begin
  a1 := 12;
  b2 := 34;
  write(a1)
end.
```

**翻译要点**：
- `var a1, b2: integer` → `int a1 = 0; int b2 = 0;`
- `a1 := 12` → `a1 = 12;`
- `write(a1)` → `pas_write_int(a1);`
- 包含运行时 I/O helper 函数

### 02_lex_error — 词法错误

**Pascal 源码**（[02_lex_error.pas](../samples/02_lex_error.pas)）：（含非法字符 `@` 等）

**预期行为**：词法分析阶段报错，输出 `E110 Unknown character`，不生成 .c 文件。

### 03_controlflow — 控制流语句

**Pascal 源码**（[03_controlflow.pas](../samples/03_controlflow.pas)）包含：
- `while i < 3 do ...`
- `if i == 1 then ... else ...`
- `for i := 1 to 2 do ...`
- `for i := 3 downto 1 do ...`
- `repeat ... until` 结构

**翻译要点**：
- Pascal `:=` → C `=`
- Pascal `=` → C `==`
- `for i := A to B do` → `for (i = A; i <= B; ++i)`
- `for i := A downto B do` → `for (i = A; i >= B; --i)`
- `repeat stmts until cond` → `do { stmts } while (!(cond));`

### 04_routines — 过程与函数

**Pascal 源码**（[04_routines.pas](../samples/04_routines.pas)）：
```pascal
program routines;
var x: integer;

procedure inc1(a: integer);
begin
  x := x + a
end;

function add1(v: integer): integer;
begin
  add1 := v + 1
end;

begin
  x := 1;
  inc1(2);
  x := add1(x)
end.
```

**翻译要点**（对比 [04_routines.c](../samples/04_routines.c)）：
- `procedure inc1(a: integer)` → `void inc1(int a)`
- `function add1(v: integer): integer` → `int add1(int v)`
- 函数名赋值 `add1 := v + 1` → `return v + 1;`
- 全局变量 `x` 在过程体中被修改（闭包访问）
- Pascal 中函数可以在定义前被调用 — 代码生成器的两遍扫描策略解决此问题

### 05_realmap — 实数类型

**Pascal 源码**（[05_realmap.pas](../samples/05_realmap.pas)）包含：
- `var x: real` → float 类型映射
- `function addh(v: real): real` → float 参数与返回
- `x := 1.25` → 实数字面量赋值
- `x := addh(x)` → 实数函数调用

**翻译要点**：
- Pascal `real` → C `float`
- 实数 I/O 使用 `pas_write_real()` / `pas_read_real()`
- 实数常量使用 `static const float`

│  "b2"      → Identifier      ":"      → Colon                │
│  "integer" → KwInteger       ";"      → Semicolon            │

## Pascal-S 语言覆盖范围

### 已支持的特性

| 特性 | 状态 | 示例 |
|------|------|------|
| 程序结构 | program...begin...end. | program demo; begin end. |
| 基本类型 | integer, real, boolean, char | var x: integer |
| 数组 | 多维、自定义上下界 | array[1..10, 1..5] of real |
| 常量 | 整数、实数、字符、布尔 | const pi = 3.14 |
| 赋值 | := | a := a + 1 |
| 算术运算 | +, -, *, /, div, mod | a + b * c |
| 逻辑运算 | and, or, not | (a > 0) and (b < 10) |
| 关系运算 | =, <>, <, <=, >, >= | if a <> b then |
| 条件 | if-then-else | if x > 0 then ... else ... |
| 多分支 | case-of | case x of 1,2: ...; 3: ... end |
| 循环 | while-do, for-to/downto-do, repeat-until | for i := 1 to 10 do |
| 过程 | 带参数（含 VAR 引用参数） | procedure p(var x: integer) |
| 函数 | 带返回值 | function f(x: integer): integer |
| I/O | read/readln, write/writeln | write('Hello') |
| 注释 | { ... }, // ... | { block comment } |

### 未实现 / 部分支持的特性

| 特性 | 状态 |
|------|------|
| record 类型 | Bison 文法支持，代码生成未实现 |
| type 别名 | Bison 文法支持，代码生成未处理 |
| 程序参数列表 | 文法解析但忽略 |
| goto/label | 不在 Pascal-S 子集中 |
| set 类型 | 不在 Pascal-S 子集中 |
| pointer 类型 | 不在 Pascal-S 子集中 |
| file 类型 | 不在 Pascal-S 子集中 |
| with 语句 | 不在 Pascal-S 子集中 |
| 字符串字面量 | 不支持 |
| 嵌套子程序 | 未测试 |
