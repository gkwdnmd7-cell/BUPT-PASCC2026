## 构建系统 (CMake)

### 项目配置


### Flex/Bison 集成

```cmake
# [CMakeLists.txt:10-37]
# 查找 win_flex/win_bison (Windows) 或 flex/bison (Unix)
find_program(BISON_EXECUTABLE NAMES win_bison bison)
find_program(FLEX_EXECUTABLE NAMES win_flex flex)

# 自定义命令：从 .y/.l 源文件生成 C/C++ 代码
add_custom_command(
    OUTPUT parser_bison.tab.c / parser_bison.tab.h      # Bison → C
    COMMAND ${BISON_EXECUTABLE} -d -o ... parser_bison.y
)
add_custom_command(
    OUTPUT lexer_flex.cpp / lexer_flex.h                  # Flex → C++
    COMMAND ${FLEX_EXECUTABLE} --header-file=... lexer_flex.l
    DEPENDS ... parser_bison.tab.h                        # Flex 依赖 Bison 头文件
)
```

生成的 `.tab.h` 包含 Token 编号宏定义（`T_IDENTIFIER`, `T_BEGIN` 等），被 Flex 和桥接层共享。

### 目标架构

```
libraries:
  parser_bison      — Bison 生成的语法分析器 + 桥接层 (parser_bison_bridge.cpp)
  lexer_frontend    — Flex 生成的词法分析器 + 封装层 (lexer.cpp)

executables:
  pascc             — 编译器主程序
  *_tests           — 12 个测试可执行文件
```

```cmake
# [CMakeLists.txt:39-53]  parser_bison 库
add_library(parser_bison
    ${BISON_OUTPUT_C}                  # Bison 生成的 .tab.c
    src/parser_bison_bridge.cpp        # yylex/yyerror 桥接
)
target_include_directories(parser_bison PUBLIC include ${CMAKE_CURRENT_BINARY_DIR})

# [CMakeLists.txt:49-60]  lexer_frontend 库
add_library(lexer_frontend
    src/lexer.cpp                      # Lexer 类封装
    ${FLEX_OUTPUT_C}                   # Flex 生成的 .cpp
)
# Windows: YY_NO_UNISTD_H 宏确保跨平台编译

# [CMakeLists.txt:62-71]  pascc 主程序
add_executable(pascc
    src/main.cpp
    src/compiler_driver.cpp
    src/code_generator.cpp
    src/parser.cpp
    src/semantic_declaration.cpp
)
target_link_libraries(pascc PRIVATE parser_bison lexer_frontend)

# [CMakeLists.txt:74-76]  静态链接 (仅 Linux)
if(NOT WIN32)
    target_link_options(pascc PRIVATE -static -static-libstdc++ -static-libgcc)
endif()
```

## 测试体系总览

所有测试通过 CTest 注册（`add_test(NAME ... COMMAND ...)`），运行方式：`ctest` 或在构建目录执行对应可执行文件。

共 12 个测试目标，分为 4 个层级：

|--------|--------|---------|
| `semantic_tableset_tests` | [tests/semantic_tableset_tests.cpp](../tests/semantic_tableset_tests.cpp) | TableSet/ScopeStack 数据结构的插入、查找、链式作用域 |
| `semantic_typepool_tests` | [tests/semantic_typepool_tests.cpp](../tests/semantic_typepool_tests.cpp) | BuiltinTypePool 类型池的创建与查询 |

这两个测试不链接 lexer/parser 库，仅测试纯数据结构逻辑。

## 测试命名约定

每个测试函数内的断言使用描述性名称 `"module_feature_detail"` 格式：
- `codegen_template_basic_ok`
- `codegen_controlflow_while`
- `gate_semantic_fail_exit_code_9`

通过 `expect(cond, name)` 函数统一输出 `[PASS]` / `[FAIL]` 格式。
