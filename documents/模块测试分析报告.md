# Pascal-S 编译器测试方法与结果（持续维护）

## 0. 文档定位

本文档作为“统一测试方法 + 分阶段结果记录”的唯一入口。后续 M3、M4、M5、M6 的测试，都在本文件按相同结构追加，不再新开平行文档。

## 1. 统一测试方法（适用于 M2 及后续）

### 1.1 测试目标

1. 每个阶段的功能可验证（功能正确性）。
2. 每次代码变更可回归（自动化测试可重复执行）。
3. 命令行行为稳定（退出码、错误输出、产物路径可检查）。

### 1.2 标准执行流程

在项目根目录执行：

```powershell
cmake -S . -B build_fresh -G "Visual Studio 17 2022" -A x64
cmake --build build_fresh --config Debug
ctest --test-dir build_fresh -C Debug --output-on-failure
```

阶段性端到端验证：

```powershell
.\build_fresh\Debug\pascc.exe -i .\samples\01_features.pas
$LASTEXITCODE

.\build_fresh\Debug\pascc.exe -i .\samples\02_lex_error.pas
$LASTEXITCODE
```

### 1.3 通用通过标准

1. 配置成功：出现 Configuring/Generating done。
2. 构建成功：目标可执行文件生成成功。
3. 自动化测试通过：ctest 显示 0 failed。
4. 合法输入：退出码为 0，产物路径正确。
5. 非法输入：退出码符合阶段定义，错误信息包含错误码与定位信息。

### 1.4 证据记录规则

1. 记录命令、结果、判定三项。
2. 记录失败时必须给出原因与处理动作。
3. 新阶段更新时只追加新节，不改历史结论。
