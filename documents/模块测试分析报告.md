# Pascal-S 编译器测试方法与结果（持续维护）

## 0. 文档定位

本文档作为“统一测试方法 + 分阶段结果记录”的唯一入口。后续 M3、M4、M5、M6 的测试，都在本文件按相同结构追加，不再新开平行文档。

## 1. 统一测试方法（适用于 M2 及后续）

### 1.1 测试目标

1. 每个阶段的功能可验证（功能正确性）。
2. 每次代码变更可回归（自动化测试可重复执行）。
3. 命令行行为稳定（退出码、错误输出、产物路径可检查）。

### 1.2 标准执行流程

在项目根目录执行：

```powershell
cmake -S . -B build_fresh -G "Visual Studio 17 2022" -A x64
cmake --build build_fresh --config Debug
ctest --test-dir build_fresh -C Debug --output-on-failure
```

阶段性端到端验证：

```powershell
.\build_fresh\Debug\pascc.exe -i .\samples\01_features.pas
$LASTEXITCODE

.\build_fresh\Debug\pascc.exe -i .\samples\02_lex_error.pas
$LASTEXITCODE
```

### 1.3 通用通过标准

1. 配置成功：出现 Configuring/Generating done。
2. 构建成功：目标可执行文件生成成功。
3. 自动化测试通过：ctest 显示 0 failed。
4. 合法输入：退出码为 0，产物路径正确。
5. 非法输入：退出码符合阶段定义，错误信息包含错误码与定位信息。

### 1.4 证据记录规则

1. 记录命令、结果、判定三项。
2. 记录失败时必须给出原因与处理动作。
3. 新阶段更新时只追加新节，不改历史结论。

## 2. M2 词法阶段测试结果（已完成）

### 2.1 测试范围

1. 词法识别：关键字、标识符、整数/实数/字符常量、运算符、界符、注释。
2. 词法错误：E105、E106、E107、E109、E110、E199。
3. 驱动行为：词法失败退出码为 7。
4. 自动化测试：词法测试集与冒烟测试集。

相关文件：

1. [src/lexer.cpp](src/lexer.cpp)
2. [src/compiler_driver.cpp](src/compiler_driver.cpp)
3. [tests/lexer_tests.cpp](tests/lexer_tests.cpp)
4. [tests/lexer_smoke_tests.cpp](tests/lexer_smoke_tests.cpp)
5. [samples/01_features.pas](samples/01_features.pas)
6. [samples/02_lex_error.pas](samples/02_lex_error.pas)

### 2.2 环境与执行结果

1. CMake 环境：可用（cmake 4.3.1）。
2. 编译工具链：Visual Studio Build Tools 2022 可用，CMake 识别 MSVC 19.44.35225.0。
3. 配置结果：成功，build 文件生成于 [build_fresh](build_fresh)。
4. 构建结果：成功，生成 pascc.exe、lexer_tests.exe、lexer_smoke_tests.exe。
5. 自动化测试结果：ctest 2/2 通过，0 失败。

### 2.3 端到端判定

1. 合法样例通过，返回码为 0。
2. 非法样例按预期失败，输出词法错误并返回码为 7。
3. M2 达到“可构建、可执行、可报错、可回归”验收标准。
